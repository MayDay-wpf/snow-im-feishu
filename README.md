# 飞书连接（com.snow.im-feishu）

把飞书当作 Snow App 的轻量入口：不用公网服务器、不用域名，只要一个自建应用的
App ID / App Secret，就能在飞书私聊或群里下任务、看流式回复、批准工具授权、
回答选择题，并把发来的图片与文件交给绑定会话处理。

对应需求：[Issue #332 IM Connect](https://github.com/MayDay-wpf/snow-app/issues/332) 的飞书渠道。

## 前置条件

1. 在[飞书开放平台](https://open.feishu.cn/)创建**企业自建应用**，拿到 App ID 与 App Secret。
2. 「事件与回调」→ 订阅方式选择**使用长连接接收事件**，订阅 `im.message.receive_v1`。
3. 「权限管理」开通：`im:message`、`im:message.p2p_msg:readonly`（获取用户发给机器人的单聊消息）、
   `im:message.group_at_msg:readonly`（接收群聊中 @机器人 的消息）、`im:message:send_as_bot`、`im:resource`。
   > 只开通 `im:message` 时，长连接会正常建立、群聊 @机器人 也正常，但**一条单聊消息都收不到**——
   > 飞书把单聊与群聊的接收权限拆成了两个，必须单独开通 `im:message.p2p_msg:readonly`，
   > 私聊白名单申请才会出现在面板里。
4. 发布版本并让企业管理员审核通过（或用测试企业自行安装）。
5. 在 Snow App 中打开右侧面板「飞书连接」，填入 App ID 与 App Secret 并保存。

> 长连接由插件后台模块用 WebSocket 建立，不需要公网回调地址，也不开放任何入站端口。

## 依赖的宿主能力

- 插件**常驻后台模块**（`plugin.json` 的 `background`）与 `ctx.secrets`（Electron safeStorage）。
- `ctx.ws.connect` 的**二进制帧发送**（`link.sendBinary(base64)`）：飞书长连接的帧是私有
  protobuf（`pbbp2.Frame`），必须以二进制帧发送心跳与事件回执。该能力随 Snow App 一并提供。

## 使用

| 操作 | 说明 |
| --- | --- |
| 直接发消息 | 首次自动在「默认项目」下新建会话并绑定该聊天；之后消息投递到同一会话 |
| 绑定会话被删 | 投递失败时自动解绑，并在「默认项目」下新建会话重新投递原内容 |
| 发送图片 | 下载后以 `@@image:data:<mime>;base64,…@@`（data URL）交给会话，立即可预览；落库时宿主自动落盘成 `upload/<日期>/<hash>.<ext>` 短标签 |
| 发送文件 / 视频 | 下载到 `~/.snowapp/feishu-inbox/<日期>/` 后以 `@@file:<路径>@@` 交给会话 |
| 图文混排 | 富文本（`post`）里的文字、图片、视频/文件节点分别提取后一起交给会话 |
| `/new [标题]` | 新建会话并重新绑定本聊天 |
| `/stop` | 中止当前绑定会话的运行 |
| `/status` | 查看连接状态、绑定会话与统计 |
| `/model [档案名]` | 查看或切换绑定会话的 API 档案（`-` 表示跟随全局） |
| `/unbind` | 解除本聊天与 Snow 会话的绑定 |
| `/help` | 命令帮助 |
| 回复「批准 / 拒绝」 | 结算推送过来的工具授权（敏感命令只能由电脑端确认） |
| 回复「1,3」或自定义答案 | 回答推送过来的选择题 |

## 面板设置

- **应用凭证**：App ID 与 App Secret；密钥写入系统安全存储（Windows DPAPI / macOS 钥匙串 /
  Linux 密钥环），面板只提交一次、不落明文。
- **默认项目**：新会话创建在该项目下；**API 档案**：新建会话时绑定的档案。
- **回复方式**：流式回推（按 1 秒节流持续编辑同一条消息）或仅最终结果。
- **群聊需 @机器人**：群消息未 @机器人 时静默忽略。
- **允许所有私聊**：关闭时只有白名单用户可用；未授权用户的标识会出现在面板中，可一键批准或忽略。
- **驱动时切换桌面焦点**：与手机远控一致，把桌面切到该会话（审批回包需要该会话是激活会话）。
- **转发待审批与提问**：把当前激活会话的待授权 / 待答提问推到飞书。

## 行为说明

- **准入**：私聊走白名单（或全放开），群聊必须 @机器人；两者都只接受真人发送者（忽略机器人）。
- **流式回推（卡片）**：飞书只能更新**卡片**消息（对文本消息调用更新接口会返回
  `230001 This message is NOT a card`），所以流式正文放在卡片里持续更新（1 秒节流）；
  超过 3500 字符时展示尾部窗口，收尾时用首片覆盖并分片补齐（断点在代码围栏内会补上闭合并在下一片重开，
  断点在 Markdown 表格内会重复表头）。卡片不可用时该回合自动降级为一次性回推。
- **仅最终结果**：回合结束后一次性发送（长文本分片）；全程不建消息、不改消息，所以不会重复。
- **会话自愈**：绑定会话被删除后，下一条消息会先自动新建会话并重新绑定，不再卡在 `Conversation not found`。
- **附件**：图片以 `@@image:data:<mime>;base64,…@@` 交给会话 —— 渲染层把标签值**原样**当
  `<img src>` 用，只有 data URL 在刚发出去时就能预览（宿主自带输入框与手机远控同款形态）；
  落库时宿主会把 data URL 落盘成 `upload/<日期>/<hash>.<ext>` 短标签，数据库不会被 base64 撑大。
  其它文件落到 `feishu-inbox/<日期>/`，以 `@@file:<绝对路径>@@` 交给会话。
  富文本消息里的图片 / 视频节点与文字一起提取。
- **断线补发**：飞书接口调用失败时最终结果进入补发队列，网络恢复后自动补发，不重跑工具与审批。
- **重连**：长连接断开后按 2 秒起指数退避重连（上限 60 秒，带抖动），每次重连重新做端点引导。

## 已知边界

- 附件下载失败**不会吞掉整条消息**：文字照常投递，并在消息里附上失败原因（如
  `[图片下载失败：资源下载失败（HTTP 400：{"code":234009,...}）]`）。该接口的 400 多为：
  `234009` 缺少 `im:resource` 权限（补权限后要重新发布版本）、`234003` 资源不属于该消息、
  `234004` 应用不在消息所在会话、`234037` 资源超过 100MB。
- 流式回推依赖卡片接口：卡片发送或更新失败（例如缺少卡片相关权限）时，该回合会记录日志并降级为
  一次性回推——内容不丢，但可能多出一条纯文本消息。
- `interactions` 元数据域只覆盖**当前激活会话**（与手机远控同源）：绑定会话不是激活会话时，
  其待审批 / 待答提问不会转发；打开「驱动时切换桌面焦点」可以让 IM 驱动的会话成为激活会话。
- 二进制附件（图片 / 文件）走 Node 的 TLS 栈下载：后台模块的 `ctx.net.fetch` 会把响应体按
  UTF-8 解码，不能用于二进制；JSON 接口仍走 `ctx.net.fetch`（复用应用代理）。
- 面板每秒读一次插件存储（后台模块不向面板推送），状态最多有 1 秒延迟。

## 图标与上架

- **安装后**：插件列表、面板标签页与面板标题都用 `assets/feishu.svg`（`plugin.json` 的 `icon` 与
  `panels[].icon` 指向插件目录内的相对路径）。
- **官方市场条目**（snow-plugin-store 的 `app/plugins/com.snow.im-feishu.json`）：市场条目在安装前没有
  插件目录可读，`icon` 要写宿主能直接渲染的值——`lucide:Name`、`https://...`（经图片代理显示）或
  `data:image/...`。本插件建议写：
  `"icon": "https://raw.githubusercontent.com/<owner>/<repo>/main/assets/feishu.svg"`。
- **社区通道**：无需额外配置——客户端会读取仓库默认分支 `plugin.json` 的 `icon`，插件内相对路径自动
  按仓库 raw 地址展开，因此 `assets/feishu.svg` 在社区列表里同样显示为飞书标识。

## 开发提示

- 后台入口 `background.mjs` 每次启动都会重新加载，但它 import 的 `lib/*.mjs` 会被 Node
  的模块缓存复用：改动 `lib/` 下的文件后需要**重启应用**（或让插件重新安装一次）才会生效。
- 面板代码（`index.js`）随面板打开重新加载，改完直接重开面板即可。

## 文件结构

```
plugin.json          插件清单（面板 + 常驻后台模块 + 隐私声明）
assets/feishu.svg    飞书官方标识（插件列表与面板标签页图标）
index.js             设置面板（ESM 单文件，blob 加载不支持相对导入）
background.mjs       常驻后台模块入口（配置热更新、密钥交接、生命周期）
lib/proto.mjs        飞书长连接帧编解码（pbbp2 protobuf）
lib/connection.mjs   长连接（端点引导、心跳、事件回执、分片重组、重连）
lib/feishu.mjs       飞书 OpenAPI（租户令牌、发消息、更新消息、资源下载、长文本分片）
lib/router.mjs       路由（准入、绑定、命令、流式回推、审批回包、附件、补发）
lib/store.mjs        插件存储读写（配置 / 状态 / 绑定 / 补发队列）
styles.css           面板样式（只使用主题变量）
locales/*.json       面板文案
```
